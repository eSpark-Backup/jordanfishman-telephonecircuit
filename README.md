# Bluetooth Portable Rotary Phone
#### Client Name: Jordan Fishman

## Project Requirements
Below mentioned are some of the core features of the design.
- The board must be based off of an existing Spartfun design available at [this link](https://www.sparkfun.com/products/retired/9803). The link contains full information related to source code, documentation, schematics etc necessary to clone things.
- The board must have a single controller solution that is reliable and effective at the same time.
- The board must be able to support accepting analog audio from microphone and transmit to the speaker.
- The board must have Bluetooth support in design via a2dp.
- Dimensions must be around same size as the original board.
- Power to the board should be compatible with USB range. There should be two ways to power board, either via USB or via DC Jack.
